# Trailmakers Hovercraft League

This monorepo is for the [Trailmakers Hovercraft League](https://discord.gg/emTsXD7dct). It has four parts:

- **[Rules](rules/)**: The rules for the league.
- **[Website](https://junerhobart.github.io/trailmakers-hovercraft-league/)**: The rules in an website.
- **[Trailmakers mod](mod/hovercraft-soccer-league/)**: Handles teams, kickoffs, respawns, penalties, and match results.
- **[Discord bot](bot/)**: The bot for the discord server.
